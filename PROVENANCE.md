# Provenance

Atrinik Observatory is an Atrinik-authored MIT repository. The dashboard copy,
styles, TypeScript normalizer, SQL migrations, and deployment documentation in
this repository are original work for the Observatory issue.

The component coordinates are a deliberate, normalized projection of the
Atrinik workspace manifest in `atrinik/atrinik/components.json`; the manifest is
the authority for repository ownership and stack relationships. GitHub links,
workflow names, release tags, asset URLs, and probe URLs are runtime evidence or
operator configuration, not copied source material.

Third-party packages remain under their own licenses. See
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md), the package lockfile, and
the package metadata for exact versions and notices.
