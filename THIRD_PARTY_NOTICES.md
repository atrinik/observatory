# Third-party notices

The build uses Astro, TypeScript, Prettier, Vitest, Wrangler, and Cloudflare
Workers type definitions. Their source and license information is obtained from
the pinned npm package lockfile at install time. No third-party runtime code is
copied into this repository.

Cloudflare Pages, Workers, and D1 are provider services. Provider-controlled
headers, certificates, logs, and deployment metadata are outside this
repository's authorship boundary.
